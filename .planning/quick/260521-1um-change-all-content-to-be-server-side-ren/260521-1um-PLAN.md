# Quick Task 260521-1um: Change All Content to Server-Side Rendered

**Goal:** Convert all content components from `"use client"` to Server Components in Next.js App Router. This reduces client-side JS, improves SSR, and helps SEO. Interactive elements (modals, click handlers) get extracted into small isolated client components.

## Task 2: Convert Intro.tsx to Server Component

**Files:**
- `src/components/Home/Intro.tsx` (modify)
- `src/components/Home/DownloadButton.tsx` (create new)
- `src/app/[lang]/page.tsx` (pass `lang` prop)

**Action:**

Create `src/components/Home/DownloadButton.tsx`:
```tsx
"use client";

import { HiDownload } from "react-icons/hi";
import { handleDownloadFile } from "@/lib/utils";
import toast from "react-hot-toast";

export default function DownloadButton({ lang, label, toastSuccess }: { lang: string; label: string; toastSuccess: string }) {
  return (
    <button
      className="group bg-white px-7 py-3 flex items-center gap-2 rounded-full outline-none focus:scale-110 hover:scale-110 active:scale-105 transition cursor-pointer borderBlack dark:bg-white/10"
      onClick={() => {
        handleDownloadFile(`/resumes/resume_${lang}.pdf`, `resume_${lang}.pdf`);
        toast.success(toastSuccess);
      }}
    >
      {label}{" "}
      <HiDownload className="opacity-60 group-hover:translate-y-1 transition" />
    </button>
  );
}
```

Modify `src/components/Home/Intro.tsx`:
- Remove `"use client"`
- Remove imports: `useSectionInView`, `useRouteParams`, `handleDownloadFile`, `toast`, `HiDownload`
- Add `lang` prop: `export default function Intro({ t, lang }: { t: any; lang: string })`
- Replace the download `<button>` block with `<DownloadButton lang={lang} label={t.intro.download_cv} toastSuccess={t.toast.download_success} />`
- Remove the `motion` wrappers: `<motion.h1>` → `<h1>`, `<motion.p>` → `<p>`, `<motion.div>` → `<div>`
- Remove framer-motion import
- Keep `ref` section: `const { ref } = useSectionInView(...)` is removed, drop `ref` from outer section too

Modify `src/app/[lang]/page.tsx`:
- Change `<Intro t={t} />` → `<Intro t={t} lang={lang} />`

**Verify:** `Intro.tsx` has no `"use client"`. `DownloadButton.tsx` has `"use client"`. `page.tsx` passes `lang`.
