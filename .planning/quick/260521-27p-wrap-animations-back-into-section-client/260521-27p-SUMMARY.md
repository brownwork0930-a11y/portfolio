# What was done

Restored all framer-motion animations removed during the SSR conversion. The pattern used:
Server Component passes children to a Client Component wrapper — children are SSR'd, the
wrapper provides the animation layer. Content text never moves to the client bundle.

## New client wrapper components

| File | Used by | Animation |
|------|---------|-----------|
| `AnimatedSection.tsx` | About.tsx | fade-in section on mount |
| `AnimatedBadge.tsx` | Skills.tsx | whileInView stagger per skill tag (motion.span) |
| `AnimatedBadgeLi.tsx` | SoftSkills.tsx | whileInView stagger per soft skill (motion.li) |
| `FadeInElement.tsx` | Intro.tsx | fade-in h1/p/div on mount via `tag` prop |
| `ProjectScrollWrapper.tsx` | Project.tsx | scroll-based scale+opacity (useScroll/useTransform) |

## Updated components

- `About.tsx` — wraps children in `<AnimatedSection delay={0.175}>`
- `Skills.tsx` — wraps each badge in `<AnimatedBadge index={idx}>`
- `SoftSkills.tsx` — wraps each item in `<AnimatedBadgeLi index={idx}>`
- `Intro.tsx` — wraps h1/p/button-row in `<FadeInElement tag="..." delay={...}>`
- `Project.tsx` — wraps entire card in `<ProjectScrollWrapper>`
- `SectionDivider.tsx` — restored `"use client"` directly (no children, decorative only)
